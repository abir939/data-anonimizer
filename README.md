# Outil d'Anonymisation de Données Cliniques 🔒

Un outil automatisé de préservation de la confidentialité conçu pour anonymiser les ensembles de données de santé et cliniques sensibles. L'application utilise des expressions régulières (Regex) ciblées pour protéger la vie privée des patients et se conformer aux protocoles de gouvernance des données.

## Fonctionnalités Principales
* **Masquage Automatisé des Données :** Nettoie les textes sensibles et remplace les informations personnelles identifiables (PII).
* **Interface Web Conviviale :** Accessible directement dans n'importe quel navigateur web.
